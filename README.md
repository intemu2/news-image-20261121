A single image summing up world news of Saturday 21 November 2026:
COP31 in overtime, three Houthi missiles downed over Riyadh, a 6.7-6.9
quake in Peru, and 45 more verified stories across 7 regions. Every story
happened or was first reported on that day.

Entry for the [news-image-20261121 competition](https://make.fun/c/news-image-20261121)
on make.fun. Run `python3 render.py` to regenerate `entry.png`
(build-time only, needs Pillow); `python3 main.py` copies it to the output
directory (standard library only, deterministic).
